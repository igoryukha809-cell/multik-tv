# МУЛЬТИК ТВ — серверная платформа

Компоненты: SRS (RTMP ingest/HLS), Node.js API, FFmpeg автоэфирный директор, постоянные Docker volumes и модуль статистики.

## API
- `GET /health` — состояние API.
- `GET /api/channel` — реальный статус наличия HLS-плейлиста и директор.
- `GET /api/director` — состояние автоэфира.
- `GET /api/discovery?q=cartoons` — поиск записей Internet Archive (только метаданные).
- `GET /api/learning` — агрегированная статистика.
- `POST /api/learning/event` и `POST /api/learning/recommend` — требуют действующую административную сессию Logto.
- `GET /hls/live/multiktv.m3u8` — видеопоток.

## Административный доступ

Административные запросы защищены только через Logto. Перед запуском задайте в локальном `.env` переменные `ADMIN_EMAIL`, `LOGTO_ENDPOINT` и `LOGTO_API_RESOURCE`. Используйте тот же Logto tenant и API resource, что и в `logto-config.js`. Сервер проверяет подпись JWT, issuer, audience, срок действия и подтверждённую почту через Logto UserInfo. Не добавляйте в браузер секретные ключи.

## Автоэфир
Положите видеофайлы, на которые подтверждены права публичного показа, в Docker volume `media-data`. Создайте `schedule.json` в volume `schedule-data`:
```json
{"items":[{"title":"Название","file":"cartoon.mp4","rightsCleared":true}]}
```
Директор автоматически запускает FFmpeg, передаёт плейлист в SRS и перезапускает кодировщик после сбоя. Без разрешённых файлов он ждёт, а не включает случайные ролики.

## Запуск
Требуется Docker Compose на постоянно работающем сервере:
```sh
docker compose up -d --build
docker compose ps
```
RTMP input: `rtmp://HOST/live/multiktv`; HLS: `http://HOST:8080/hls/live/multiktv.m3u8`.
GitHub Pages не исполняет серверный код. Для публичного доступа нужен хост с открытыми портами/доменом, TLS-прокси для API/HLS и ограничением доступа к панели. Не выставляйте API управления и Docker-порты без защиты. Все административные POST/PUT-запросы проверяются сервером через Logto. Не публикуйте токены и не вставляйте их в клиентский JavaScript. Развёртывание публичной инфраструктуры и сетевую настройку поручите взрослому.

## Поиск и права
Поиск возвращает только метаданные. Запись в каталоге, ссылка на видео или поле license не являются автоматическим разрешением на ретрансляцию. Перед эфиром проверьте право на публичный показ у правообладателя и условия лицензии. Не передавайте персональные данные зрителей в модуль обучения.

## Предэфирная проверка расписания

Перед запуском директора проверьте локальное расписание и наличие каждого видеофайла:
```sh
MEDIA_DIR=/путь/к/видео SCHEDULE_FILE=/путь/к/schedule.json npm run preflight
```
Команда завершится с кодом 1, если расписание пустое, файл отсутствует или материал не отмечен оператором как имеющий подтверждённые права на публичный показ. Проверка не подтверждает лицензию юридически — документы проверяет владелец канала.
