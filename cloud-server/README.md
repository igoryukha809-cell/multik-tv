# МУЛЬТИК ТВ Cloud

Собственный небольшой HTTP-сервер на Node.js без платных библиотек и без npm-зависимостей.

## Что он делает

- `GET /health` — проверка процесса сервера.
- `GET /api/channel` — статус наличия HLS-плейлиста.
- `GET /hls/live.m3u8` — отдача HLS-плейлиста и сегментов из папки `hls/`.
- Поддерживает переменную окружения `PORT`, которую обычно задаёт хостинг.
- Не содержит административных команд или публичной загрузки файлов.

## Запуск локально

Требуется Node.js 20 или новее:

```sh
cd cloud-server
npm start
```

Откройте `http://localhost:8080/health`.

Положите готовый HLS-вывод (файл `live.m3u8` и сегменты) в `cloud-server/hls/`. Сам Node.js-сервер не кодирует видео и не создаёт эфир: для этого отдельно нужен источник видео и FFmpeg/SRS.

## Нулевая стоимость

Исходный код и Node.js бесплатны. Этот проект не подключает платные API, базы данных или платные тарифы. Но размещение на общедоступном сервере зависит от условий хостинга: бесплатные тарифы могут ограничивать часы работы, трафик, объём хранения или приостанавливать приложение. Само добавление кода в GitHub не запускает его как сервер.

Не добавляйте секреты, ключи или персональные данные в репозиторий. Для публичной трансляции используйте только контент, на который у канала есть разрешение на публичный показ.


## Поиск мультфильмов в интернете

Серверный API `GET /api/discovery?q=cartoons` ищет записи в каталоге Internet Archive и возвращает названия, страницы источников и сведения о лицензии, если они указаны. Пример:
```sh
curl "http://localhost:8080/api/discovery?q=русские%20мультфильмы"
```
Это поиск метаданных, а не автоматическое скачивание или разрешение на эфир. Записи нужно проверить вручную: поле лицензии может отсутствовать или быть неполным. Автоэфир допускает только локальные файлы, явно внесённые в расписание с `rightsCleared: true`.
