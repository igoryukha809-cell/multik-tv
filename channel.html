Что уже работает бесплатно

Сайт размещён на GitHub Pages. GitHub Actions автоматически проверяет файл расписания каждые 15 минут и обновляет статус готовности.

Важно: потоковый сервер подключён и формирует HLS-видеосегменты. Статус «Эфир подтверждён» появляется только после проверки актуального манифеста и медиасегмента. Бесплатный тариф хостинга не гарантирует круглосуточную доступность.

Следующие необходимые шаги

  1. Добавить только русскоязычные мультфильмы, на публичный показ которых получено разрешение.
  2. Получить разрешённые видеофайлы или потоковые URL.
  3. Подключить постоянно работающий видеосервер. Бесплатный статический GitHub Pages этого не заменяет.
