# Облачное хранилище и ключи МУЛЬТИК ТВ

Сервис использует Backblaze B2 через S3-совместимый API. Административные операции менеджера ключей защищены единственной системой авторизации проекта — Logto.

## Настройка хранилища

Учётную запись, ключи и любые платёжные настройки должен контролировать взрослый владелец.

1. Включить B2 Cloud Storage и создать bucket для видео.
2. Создать Application Key, ограниченный нужным bucket и требуемыми правами.
3. Сохранить keyID и applicationKey в защищённом месте. Секрет показывается только один раз. Не использовать Master Application Key.

## Переменные окружения сервера

Хранилище:
- `B2_BUCKET` — имя bucket.
- `B2_ENDPOINT` — S3 endpoint.
- `B2_REGION` — регион endpoint.
- `AWS_ACCESS_KEY_ID` — keyID.
- `AWS_SECRET_ACCESS_KEY` — applicationKey.

Авторизация администратора через Logto:
- `LOGTO_ENDPOINT` — endpoint проекта Logto.
- `LOGTO_API_RESOURCE` — URI API resource, совпадающий с настройкой Logto.
- `ADMIN_EMAIL` — подтверждённый email администратора.

Дополнительные параметры:
- `DATA_DIR` — каталог данных, например `/var/data`.
- `ACCESS_KEYS_FILE` — необязательный путь к файлу ключей.
- `ALLOWED_ORIGINS` — разрешённые origins сайта.
- `UPLOAD_API_TOKEN` — необязательный устаревший токен загрузки; он не является способом входа администратора.

Все секреты задаются только в защищённых переменных сервера. Не помещать их в GitHub, HTML/JavaScript, логи или сообщения. Для сохранности локального файла ключей нужен постоянный диск; при использовании B2 список ключей хранится в объекте `system/access-keys.json`.

## Менеджер ключей доступа

Страница: `/access-keys.html`.

- `upload` — разрешает загрузку видео.
- `api` — разрешает операции API, включая загрузку и удаление видео.
- Ключ генерируется криптографически стойким генератором на сервере.
- Полный ключ показывается только один раз; в хранилище записывается только SHA-256-хеш.
- Администратор может просматривать список, видеть последнее использование и отзывать ключи.
- Доступ к менеджеру выдаётся только после проверки JWT Logto и подтверждённого email на сервере.

API менеджера:
- `GET /api/admin/keys` — список ключей.
- `POST /api/admin/keys` — создать ключ; JSON: `{"label":"Загрузчик","scope":"upload"}` или `{"label":"API","scope":"api"}`.
- `DELETE /api/admin/keys/:id` — отозвать ключ.

## Проверка

Открыть `/health`. После настройки хранилища ожидается `ok: true`, `storage: backblaze-b2` и `configured: true`.

Это объектное хранилище, а не видеотранслятор. Оно само не создаёт HLS-эфир и не обеспечивает круглосуточное вещание. Для эфира отдельно нужен playout/streaming-сервер и разрешения на публичный показ каждого материала.
