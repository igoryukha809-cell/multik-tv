# МУЛЬТИК ТВ — подключение Backblaze B2

Загрузчик использует S3-совместимый API Backblaze B2. Он выдаёт временную ссылку для прямой загрузки из браузера в B2; сам видеопоток не создаёт.

## Настройка взрослым владельцем аккаунта

1. Создать Backblaze B2 bucket. Для публичного просмотра файлов выбрать публичный bucket и настроить доступ согласно документации B2.
2. Создать Application Key с доступом только к этому bucket и правами, необходимыми для загрузки и чтения. Не использовать master key.
3. В настройках bucket задать CORS для origin `https://igoryukha809-cell.github.io`, методов `PUT, GET, HEAD`, заголовков `Content-Type` (при необходимости — `*`) и expose `ETag`.
4. Создать в Render отдельный Web Service из этого репозитория: Root Directory `storage-api`, Dockerfile. Проверить доступный тариф перед созданием.
5. Задать в Render Environment (не в GitHub):
   - `B2_REGION` — код региона из S3 Endpoint bucket (например, `us-west-004`)
   - `B2_KEY_ID` — Application Key ID
   - `B2_APPLICATION_KEY` — Application Key
   - `B2_BUCKET` — точное имя bucket
   - `UPLOAD_API_TOKEN` — отдельный длинный случайный секрет для сайта
   - `PUBLIC_MEDIA_BASE_URL` — публичный URL bucket без завершающего слэша
   - `ALLOWED_ORIGINS` — `https://igoryukha809-cell.github.io`
6. Проверить `https://АДРЕС-СЕРВИСА/health`: поле `configured` должно быть true.

Никогда не помещайте ключи в HTML, GitHub, переписку или публичные файлы и не отправляйте их в ChatGPT. Подростку не следует самостоятельно создавать облачные аккаунты или ключи — настройку выполняет родитель/опекун.

## Ограничения

- Поддерживаются MP4, WebM и MOV до 5 ГБ одним PUT; большие файлы требуют multipart.
- Браузер загружает файл напрямую в B2, API только подписывает запрос.
- Загруженный файл не добавляется автоматически в эфирный плейлист. До проверки прав на публичный показ и настройки эфира он остаётся только объектом в хранилище.
- По опубликованным тарифам первые 10 ГБ хранения бесплатны, исходящий трафик включён до 3× среднемесячного объёма хранения; превышение может тарифицироваться. Условия могут меняться — взрослому владельцу аккаунта нужно проверить актуальную стоимость до включения публичной раздачи.
