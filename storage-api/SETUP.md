# МУЛЬТИК ТВ — подключение Cloudflare R2

Этот сервис только выдаёт временную ссылку для прямой загрузки браузером в R2. Сам видеопоток он не создаёт. После загрузки ещё потребуется добавить проверенный публичный URL в эфирный плейлист и настроить FFmpeg/SRS на воспроизведение.

## Требуется взрослому владельцу аккаунта

1. Создать Cloudflare R2 bucket и включить публичное чтение через отдельный публичный домен.
2. Создать R2 API token только для нужного bucket с правами Object Read & Write. Не использовать Global API Key.
3. Настроить CORS bucket: Allowed origins — `https://igoryukha809-cell.github.io`; Allowed methods — `PUT, GET, HEAD`; Allowed headers — `Content-Type`; Expose headers — `ETag`; Max age — `3600`.
4. Создать в Render отдельный Web Service из этого репозитория: Root Directory `storage-api`, Dockerfile, Free only. Проверить все параметры и не добавлять платные ресурсы.
5. Задать в Render Environment (не в GitHub):
   - `R2_ACCOUNT_ID`
   - `R2_ACCESS_KEY_ID`
   - `R2_SECRET_ACCESS_KEY`
   - `R2_BUCKET`
   - `UPLOAD_API_TOKEN` — длинный случайный секрет
   - `PUBLIC_MEDIA_BASE_URL` — публичный домен bucket без завершающего слэша
   - `ALLOWED_ORIGINS` — `https://igoryukha809-cell.github.io`
6. Проверить `https://АДРЕС-СЕРВИСА/health`: поле `configured` должно быть true.

Никогда не помещайте ключи в HTML, GitHub, переписку или публичные файлы. Не отправляйте их в ChatGPT. Подростку не следует самостоятельно создавать облачные аккаунты или ключи — пусть это сделает родитель/опекун.

## Ограничения

- Прямая загрузка одним PUT — до 5 ГБ. Для больших файлов понадобится S3 multipart upload.
- Render API не проксирует байты видео: браузер отправляет их непосредственно в R2.
- Загрузка файла не означает автоматическое включение в эфир. До проверки прав на публичный показ и настройки плейлиста он остаётся только объектом в хранилище.
- R2, публичный домен и исходящий трафик могут иметь платные лимиты/тарифы. До включения публичного доступа взрослый должен проверить актуальные цены и ограничения. Не считать использование гарантированно бесплатным.
