# Облачное хранилище и ключи МУЛЬТИК ТВ

Сервис использует Backblaze B2 через S3-совместимый API. В сервер также встроен собственный менеджер ключей доступа МУЛЬТИК ТВ.

## Настройка хранилища

Учётную запись, ключи и любые платёжные настройки должен контролировать взрослый владелец. Регистрация: https://www.backblaze.com/sign-up/s3

Официальная инструкция по созданию ключей B2: https://www.backblaze.com/docs/cloud-storage-create-and-manage-application-keys

1. Включить B2 Cloud Storage и создать bucket для видео.
2. Открыть B2 Cloud Storage → Application Keys → Add a New Application Key.
3. Ограничить ключ созданным bucket и выбрать Read and Write. Для ограниченного bucket включить Allow List All Bucket Names, необходимый для S3 List Buckets.
4. Создать ключ и сохранить keyID и applicationKey в защищённом месте. Секрет показывается только один раз. Не использовать Master Application Key.

## Переменные окружения сервера

- `B2_BUCKET` — точное имя bucket.
- `B2_ENDPOINT` — S3 endpoint из настроек bucket.
- `B2_REGION` — регион из endpoint.
- `AWS_ACCESS_KEY_ID` — keyID.
- `AWS_SECRET_ACCESS_KEY` — applicationKey.
- `ADMIN_EMAIL` — подтверждённый адрес владельца, например `Igoryukha809@gmail.com`.
- `SUPABASE_URL` — URL проекта Supabase.
- `SUPABASE_ANON_KEY` — публичный anon/publishable key проекта. Не использовать service_role.
- Менеджер ключей проверяет bearer-сессию Supabase через Auth API и сверяет подтверждённую почту с `ADMIN_EMAIL`. Отдельный `ADMIN_API_TOKEN` больше не нужен.
- `DATA_DIR` — каталог данных на постоянном диске, например `/var/data`.
- `ALLOWED_ORIGINS` — `https://igoryukha809-cell.github.io`.
- `UPLOAD_API_TOKEN` — необязательный старый ключ загрузки для совместимости.

Все секреты задаются только в защищённых переменных сервера. Не помещать их в GitHub, HTML/JavaScript, логи или сообщения. Взрослый владелец должен задать `ADMIN_API_TOKEN` и подключить постоянный диск к `DATA_DIR`: без постоянного диска выданные ключи могут потеряться после перезапуска.

## Собственный менеджер ключей

Страница: `/access-keys.html` на сайте МУЛЬТИК ТВ. Она уже добавлена в админ-панель.

- `upload` — разрешает загрузку видео.
- `api` — разрешает операции API, включая загрузку и удаление видео.
- Ключ генерируется криптографически стойким генератором на сервере.
- Полный ключ показывается только один раз; на диске хранится только SHA-256-хеш.
- Администратор может просматривать список, видеть последнее использование и отзывать ключи.
- Для входа используется одноразовая ссылка на подтверждённую почту. Сервер сверяет пользователя и `ADMIN_EMAIL`; отдельный ключ администратора не нужен.

API менеджера:
- `GET /api/admin/keys` — список ключей.
- `POST /api/admin/keys` — создать ключ; JSON: `{"label":"Загрузчик","scope":"upload"}` или `{"label":"API","scope":"api"}`.
- `DELETE /api/admin/keys/:id` — отозвать ключ.

## Проверка

Открыть `/health`. После настройки хранилища ожидается `ok: true`, `storage: backblaze-b2` и `configured: true`.

Это объектное хранилище, а не видеотранслятор. Оно само не создаёт HLS-эфир и не обеспечивает круглосуточное вещание. Для эфира отдельно нужен playout/streaming-сервер и разрешения на публичный показ каждого материала.
