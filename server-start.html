Как запустить общий интернет-эфир бесплатно

Сайт канала уже опубликован. Для настоящего общего эфира нужен отдельный компьютер-сервер, который постоянно передаёт видео. Ни GitHub Pages, ни обычная веб-страница не могут работать вместо такого сервера.

Что реально можно сделать без платы за ПО

Использовать собственный компьютер и бесплатные программы Docker, SRS и FFmpeg. Компьютер должен оставаться включённым, а интернет — работать. Это не требует аренды облака, но не является бесплатным облачным хостингом.

Важно: поскольку настройка сервера и домашней сети затрагивает безопасность, попроси родителя или опекуна помочь. Не открывай порты роутера и не публикуй домашний IP самостоятельно.

Порядок запуска на компьютере

1
На компьютере установи Docker Desktop. Для установки и принятия условий попроси взрослого помочь.
2
Открой папку stream-server в проекте и скачай проект. Помести только свои видео или материалы с явным разрешением на публичный показ в папку stream-server/media.
3
Открой папку stream-server в терминале и запусти docker compose up -d --build.
4
Проверь состояние командой docker compose ps. В домашней сети тестовый адрес потока: http://localhost:8080/live/multiktv.m3u8.
5
Для общего просмотра через интернет взрослому потребуется безопасный публичный HTTPS-адрес и проверка настроек сети. Не публикуй служебные порты или ключи.

Что пока не запущено

  • Общий публичный поток — сервер ещё не запущен.
  • Круглосуточная автоматическая передача — требует работающего компьютера.
  • Автоматический поиск с проверкой лицензий — бот пока каталог, а не автономная нейросеть.
  • Библиотека мультфильмов — в серверную папку ещё не добавлены разрешённые видео.

Доступность ролика в интернете не означает разрешение на ретрансляцию. Нужны права на публичный показ и распространение.
