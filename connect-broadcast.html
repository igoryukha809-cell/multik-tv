Подключение настоящего эфира

Страница соединяет зрительский плеер с HLS-адресом уже работающего видеосервера. Она не создаёт поток сама и не запускает сервер.

1. Текущее состояние канала

Читаю статус проекта…

Проверяемый файл: broadcast/status.json

2. Что должно быть настроено на сервере

  1. Работающий сервер SRS и автоматический отправитель FFmpeg из папки stream-server/media.
  2. В папке должны находиться только собственные видео или материалы с явным разрешением на публичную трансляцию.
  3. После запуска SRS должен сформировать HLS-плейлист /live/multiktv.m3u8.
  4. Владелец сервера вместе со взрослым должен настроить безопасный HTTPS-доступ. Не публикуй домашний IP и не открывай порты роутера самостоятельно.

Не вставляй сюда пароли, RTMP-ключи, токены или адреса административных панелей. Для просмотра нужен только публичный HTTPS HLS-адрес.

3. Проверить HLS-адрес

Вставь адрес только после того, как сервер действительно запущен.

Проверка работает в браузере. Некоторые потоки требуют CORS-настройки на сервере или браузер с поддержкой HLS. Ошибка предпросмотра не всегда означает, что сам сервер выключен.

4. Связанные инструменты

  • Инструкция SRS + FFmpeg + Docker
  • Зрительский плеер
  • Реестр разрешений на показ
  • Предэфирная проверка
