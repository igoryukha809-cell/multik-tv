# МУЛЬТИК ТВ — сервер эфира

Этот каталог содержит конфигурацию SRS для приёма RTMP из OBS и выдачи HLS-потока зрителям.

## Порты

- TCP 1935 — входящий RTMP из OBS.
- HTTP 8080 — HLS-плейлист и сегменты.
- HTTP 1985 — служебный API SRS; не публикуйте его без необходимости.

## OBS

После развёртывания сервера настройте OBS → Настройки → Трансляция:
- Сервис: Custom
- Сервер: `rtmp://<публичный-хост>:1935/live`
- Ключ: `livestream`

Не публикуйте ключ трансляции. Он даёт возможность отправлять видео на канал.

## Адрес зрительского потока

`https://<публичный-домен>/live/livestream.m3u8`

Страница плеера `/stream.html` принимает этот HTTPS URL.

## Важные ограничения

GitHub Pages не запускает этот контейнер и не передаёт RTMP. Контейнер нужно отдельно развернуть на хостинге, который разрешает входящий TCP-порт 1935 и HTTP-порт 8080. На Railway может понадобиться публичный TCP proxy для 1935 и HTTP-домен, направленный на 8080. Проверьте тарифы и лимиты вместе с родителем/опекуном до включения сервиса: постоянное вещание может расходовать платные ресурсы.

Этот сервер только передаёт сигнал. Он не предоставляет права на показ мультфильмов. Используйте собственные материалы или контент с разрешением на публичную трансляцию.
