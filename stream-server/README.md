# МУЛЬТИК ТВ — бесплатный домашний видеосервер 24/7

Подготовлен вариант на бесплатном ПО: SRS принимает RTMP, выдаёт HLS, а FFmpeg автоматически передаёт файлы из папки `media` по кругу.

## Честно о круглосуточной работе

Программы бесплатные, но для настоящего непрерывного эфира нужен компьютер, который остаётся включённым, стабильный интернет и достаточная скорость исходящей передачи. Если выключить компьютер, закрыть Docker или пропадёт интернет — эфир остановится. GitHub Pages сам видеотрансляцию не ведёт.

Для безопасной настройки сети, роутера и публикации потока в интернете попроси родителя/опекуна помочь. Не открывайте порты роутера и не публикуйте домашний IP без взрослого. Начинайте с просмотра только в домашней сети.

## Что потребуется

- Компьютер с Windows 11, macOS или Linux и Docker.
- Собственные видеофайлы либо файлы, на публичный показ которых у канала есть явное разрешение.
- Свободное место на диске и стабильный upload. При видеобитрейте около 1,8 Мбит/с одному зрителю нужно ориентировочно 2 Мбит/с исходящего канала с запасом; каждый зритель увеличивает нагрузку.

## Быстрый запуск

1. Установить Docker Desktop: https://www.docker.com/products/docker-desktop/
2. Скопировать разрешённые видеофайлы MP4/MKV/MOV/WebM в папку `stream-server/media/`.
3. Открыть терминал в папке `stream-server`.
4. Запустить: `docker compose up -d --build`.
5. Проверить: `docker compose ps` и `docker compose logs -f playlist srs`.
6. В домашней сети открыть поток: `http://localhost:8080/live/multiktv.m3u8`.

Остановка: `docker compose down`. Контейнеры настроены на автоматический перезапуск, пока Docker Engine работает. Если папка media пуста, проигрыватель ждёт и проверяет её снова.

## Бесплатный облачный хостинг: проверенные ограничения

На момент проверки не найден подтверждённый бесплатный тариф, который одновременно предоставляет собственный сервер, хранение видео и непрерывный публичный эфир 24/7 без оплаты.

- Livepush: бесплатный тариф заявляет 20 часов трансляции в месяц, до 200 МБ хранилища и ограничение до 20 минут на одно заранее записанное событие. Это подходит для коротких эфиров/тестов, но не для круглосуточного канала. Условия: https://docs.livepush.io/en/articles/6793935-livepush-plans-and-pricing
- Upstream: бесплатный RTMP-план заявляет 24 часа трансляции в месяц. Это также не 24/7-хостинг. Условия: https://upstream.so/rtmp-server/

Условия бесплатных тарифов могут меняться. Перед регистрацией проверь официальную страницу тарифа. Не добавляй банковскую карту и не переходи на платный тариф. Для регистрации и принятия условий попроси родителя/опекуна помочь.

## Для публичного просмотра через интернет

Нужен публичный HTTPS-домен или защищённый reverse proxy с TLS, доступный извне сервер и настройка маршрутизатора. Не публикуйте служебный API SRS (порт 1985) — он в этой конфигурации не открыт. Не открывайте порты роутера самостоятельно: попроси взрослого помочь с сетевой безопасностью. Провайдер может блокировать входящие соединения или использовать CGNAT. Не обещаем, что домашнее подключение поддерживает публичный хостинг.

## Права и ограничения

- Это домашний сервер, не облако: он не работает при выключенном компьютере.
- GitHub Pages не управляет сервером автоматически.
- Открытая ссылка на мультфильм, подписка на сервис или доступность ролика на YouTube не дают права на публичную ретрансляцию.
- Используй только свои материалы или контент с явным разрешением на публичный показ.
- Не помещай пароли, токены, ключи трансляции или личные данные в GitHub.
- В этой конфигурации нет DRM, аналитики зрителей или защиты от копирования.
