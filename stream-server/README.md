# МУЛЬТИК ТВ — бесплатный домашний видеосервер

Подготовлен вариант на бесплатном ПО: SRS принимает RTMP, выдаёт HLS, а FFmpeg автоматически передаёт технический тестовый сигнал. Для локального плейлиста используйте Docker Compose.

## Честно о круглосуточной работе

Программы бесплатные, но для настоящего непрерывного эфира нужен компьютер или облачный сервер, который остаётся включённым, стабильный интернет и достаточная скорость исходящей передачи. GitHub Pages сам видеотрансляцию не ведёт.

Для безопасной настройки сети, роутера и публикации потока в интернете попроси родителя/опекуна помочь. Не открывайте порты роутера и не публикуйте домашний IP без взрослого. Начинайте с просмотра только в домашней сети.

## Что потребуется для локального запуска

- Компьютер с Windows 11, macOS или Linux и Docker.
- Собственные видеофайлы либо файлы, на публичный показ которых у канала есть явное разрешение.
- Свободное место на диске и стабильный upload. При видеобитрейте около 1,8 Мбит/с одному зрителю нужно ориентировочно 2 Мбит/с исходящего канала с запасом; каждый зритель увеличивает нагрузку.

## Быстрый локальный запуск

1. Установить Docker Desktop: https://www.docker.com/products/docker-desktop/
2. Скопировать разрешённые видеофайлы MP4/MKV/MOV/WebM в папку `stream-server/media/`.
3. Открыть терминал в папке `stream-server`.
4. Запустить: `docker compose up -d --build`.
5. Проверить: `docker compose ps` и `docker compose logs -f playlist srs`.
6. В домашней сети открыть поток: `http://localhost:8080/live/multiktv.m3u8`.

Остановка: `docker compose down`. Контейнеры настроены на автоматический перезапуск, пока Docker Engine работает. Если папка media пуста, проигрыватель ждёт и проверяет её снова.

## Облачная замена Railway: Render

В корне репозитория добавлен `render.yaml` — Blueprint для Render. Он собирает Dockerfile из `stream-server/` и запускает только техническую тестовую заставку, явно помеченную как тест, а не мультфильм.

**Ограничения бесплатного тарифа Render:**
- Бесплатный веб-сервис выключается после 15 минут без входящих запросов и обычно запускается примерно за минуту после следующего обращения.
- Доступно до 750 часов работы бесплатных сервисов на рабочее пространство в календарный месяц.
- Бесплатные сервисы могут перезапускаться; постоянный диск не предоставляется.
- Это не гарантирует круглосуточную работу. При отсутствии зрителей сервис может уснуть, а после лимитов — приостановиться.
- Если добавлен способ оплаты, отдельные виды превышения включённых лимитов могут тарифицироваться. Не добавляйте платёжные данные и не соглашайтесь на платный план без родителя/опекуна.

Официальные ограничения: https://render.com/docs/free

### Как подключить Render

1. Попроси родителя/опекуна проверить условия тарифа и помочь с аккаунтом.
2. Открой https://dashboard.render.com/ и выбери создание **Blueprint**.
3. Подключи репозиторий `igoryukha809-cell/multik-tv`, ветку `main`.
4. Render прочитает `render.yaml`. Перед подтверждением проверь, что создаётся только один веб-сервис `multik-tv-test-stream` с тарифом `Free`, без базы данных, дисков и дополнительных ресурсов.
5. Не подтверждай платные ресурсы. Если настройки отличаются от описанных, остановись и попроси взрослого проверить их.
6. После успешного запуска Render покажет адрес сервиса. HLS-тестовый поток находится по пути `/live/multiktv.m3u8`.

Самостоятельное развёртывание здесь не выполнялось: создание облачного сервиса требует входа в аккаунт Render и подтверждения настроек владельцем аккаунта. Даже после запуска это будет тестовый сигнал, а не настоящий телеканал 24/7.

## Права на контент

- Открытая ссылка на мультфильм, подписка на сервис или доступность ролика на YouTube не дают права на публичную ретрансляцию.
- Используй только свои материалы или контент с явным разрешением на публичный показ.
- Не помещай пароли, токены, ключи трансляции или личные данные в GitHub.
- В этой конфигурации нет DRM, аналитики зрителей или защиты от копирования.

## Запуск и остановка одной кнопкой

После установки и запуска Docker Desktop:

- **Windows:** открой `stream-server/start-local.bat`. Для остановки открой `stream-server/stop-local.bat`.
- **macOS/Linux:** в терминале выполни `cd stream-server && bash start-local.sh`. Для остановки — `bash stop-local.sh`.

Положи разрешённые видеофайлы в `stream-server/media/` до запуска. Если папка пуста, сервер передаст только тестовую техническую заставку — это не программа канала. Локальный адрес потока: `http://localhost:8080/live/multiktv.m3u8`. Он доступен на том же компьютере; публичный доступ из интернета не включается этими скриптами.

## Проверка конфигурации перед запуском

Из корня репозитория выполни:

```sh
bash stream-server/check-config.sh
```

Скрипт проверяет синтаксис автоматического плейлиста, JSON-файлы состояния, базовые параметры SRS и, если Docker установлен, валидность Docker Compose. Успешная проверка не заменяет запуск контейнеров и проверку настоящего HLS-видеопотока.
