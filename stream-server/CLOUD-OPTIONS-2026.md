# Облачный сервер МУЛЬТИК ТВ — проверка вариантов на 18 ноября 2026

## Итог

Для круглосуточного публичного видеоканала нужны постоянно работающий процесс кодирования/передачи, место для файлов и исходящий видеотрафик. По проверенным официальным тарифам нельзя подтвердить вариант, который одновременно даёт всё это бесплатно, без остановок и без лимита трафика.

Сайт GitHub Pages остаётся бесплатной статической страницей. Он не запускает Docker, FFmpeg или SRS и не является видеосервером.

## Проверенные варианты

## Подготовленная техническая схема проекта

В репозитории уже есть Docker Compose конфигурация:
- SRS принимает RTMP и выдаёт HLS.
- FFmpeg читает локальную папку `stream-server/media` и передаёт видео по очереди.
- Если папка пуста, FFmpeg выдаёт техническую тестовую заставку.
- Состояние публичного канала пока `offline`, а плейлист пуст.

Локальный запуск требует Docker и включённого компьютера. Это не облачный сервер.

## Безопасный следующий этап

Владелец аккаунта и взрослый помощник должны выбрать и подтвердить провайдера, условия и возможные расходы. Не вводить платёжные данные в бесплатный тест, не включать платные ресурсы и лимиты расходов без проверки взрослым. Не передавать пароли, API-токены или ключи трансляции в чат или публичный репозиторий.

До появления подтверждённого постоянно работающего сервера публичный эфир должен оставаться OFFLINE. Тестовую заставку нельзя показывать как доказательство работающего круглосуточного канала.
