# МУЛЬТИК ТВ — папка видео

Помести сюда только видео, которые принадлежат тебе или для которых у канала есть письменное разрешение на публичную онлайн-трансляцию.

Поддерживаемые расширения: `.mp4`, `.mkv`, `.mov`, `.webm`.

Контейнер FFmpeg читает файлы из этой папки и передаёт их по очереди в локальный сервер SRS. Когда список заканчивается, воспроизведение начинается сначала. Если папка пуста, плейлист ждёт появления файлов.

## Перед добавлением видео

- Проверь, что разрешение прямо охватывает публичный показ/онлайн-трансляцию, а не только личный просмотр.
- Проверь отдельные права на музыку, озвучку и вставленные фрагменты.
- Сохрани письменное разрешение и атрибуцию вне публичной папки сайта.
- Не загружай чужие мультфильмы в этот репозиторий GitHub.

## Важно

Эта папка предназначена для локального сервера. Видео не загружаются на GitHub Pages автоматически. Не добавляй сюда большие медиафайлы в Git-репозиторий: используй локальную папку `stream-server/media/` на компьютере, где запущен Docker.

Пустая папка не означает, что канал работает. Без видео, запущенного Docker и доступного сервера трансляции нет.
