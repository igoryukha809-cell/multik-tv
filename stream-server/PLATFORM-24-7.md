# МУЛЬТИК ТВ — собственная платформа 24/7

Это собственная система линейного видеовещания канала. Она собрана из бесплатного открытого ПО:

- **SRS** принимает RTMP и формирует HLS.
- **FFmpeg** воспроизводит файлы из `stream-server/media` по очереди.
- **Docker Compose** запускает оба компонента и перезапускает контейнеры после сбоев.
- Публичная страница просмотра уже находится в `live.html`.

## Запуск на сервере

1. Нужен постоянно работающий Linux-сервер с Docker Engine и Docker Compose plugin.
2. Добавить в `stream-server/media/` только свои видео или файлы с явным разрешением на публичную трансляцию.
3. В каталоге `stream-server` выполнить `docker compose up -d --build`.
4. Проверить `docker compose ps` и журналы `docker compose logs --tail=100`.
5. На сервере проверить HLS: `curl -I http://127.0.0.1:8080/live/multiktv.m3u8`.
6. После настройки HTTPS-домена и безопасного доступа дать зрителям HLS URL через страницу канала.

## Важные границы

- Репозиторий GitHub Pages не является потоковым сервером.
- Docker Compose автоматически перезапускает контейнеры, но не может включить выключенный сервер или восстановить отсутствующий интернет.
- Бесплатность программ не означает бесплатность сервера, трафика и хранения.
- Ни один бесплатный облачный тариф не гарантирует постоянный видеосервер без лимитов.
- Настройку хостинга, оплаты и публичного сетевого доступа должен контролировать взрослый.
- Не публиковать ключи, токены, пароли и домашний IP в GitHub.
- Публично транслировать можно только контент, на который есть права.
