# Подключение Upstream к МУЛЬТИК ТВ

## Решение по вещанию

Для текущего этапа выбираем Upstream как облачный playout-сервис. ffplayout пока не устанавливаем: Upstream уже предоставляет облачное воспроизведение загруженной видеотеки и API управления эфиром.

Официальные ресурсы:
- Cloud playout: https://upstream.so/cloud-playout/
- API: https://upstream.so/live-streaming-api/
- API reference: https://studio.upstream.so/docs/api
- Тарифы: https://upstream.so/pricing/

## Что умеет Upstream

- Хранит видео в облачной Media Library.
- Создаёт непрерывные, разовые и повторяющиеся трансляции.
- Управляет медиатекой, папками, очередями, порядком воспроизведения и расписанием через REST API.
- Позволяет импортировать до 20 HTTPS-ссылок за раз; поддерживаются Google Drive, Dropbox, OneDrive и прямые ссылки на файлы.
- Может публиковать изменения очереди во время эфира.
- Не требует, чтобы компьютер владельца оставался включённым.

Upstream — сервис облачного вещания, а не поисковик мультфильмов. Отдельный модуль МУЛЬТИК ТВ должен находить кандидатов в открытых каталогах и проверять права; только после проверки и одобрения материалы можно импортировать в Upstream.

## Ограничения бесплатного плана

На официальной странице указано: 1 одновременный поток, 24 часа вещания в месяц, до 100 GB хранилища и 1080p30. Для непрерывного 24/7 канала нужен платный план. Тарифы и условия могут изменяться; перед включением платного тарифа взрослый владелец аккаунта должен проверить стоимость и подтвердить покупку самостоятельно.

## Безопасная схема интеграции

1. Upstream account принадлежит взрослому владельцу, который принимает условия сервиса и контролирует возможные платежи.
2. В Upstream Studio взрослый создаёт отдельный API key для МУЛЬТИК ТВ.
3. API key хранится только в защищённом backend secret store. Не добавлять его в GitHub, HTML/JavaScript, issues, commits, логи или сообщения.
4. Backend МУЛЬТИК ТВ проверяет администратора, затем вызывает Upstream REST API.
5. Поиск мультфильмов использует каталоги с явными лицензиями. Перед импортом человек проверяет, что лицензия разрешает публичный показ/трансляцию и соблюдены условия атрибуции.
6. Оригинальные мультфильмы проходят техническую и содержательную проверку до добавления в эфир.
7. Запуск/остановка эфира и публикация плейлиста требуют явного действия администратора.

## API и безопасность

Базовый адрес API: https://studio.upstream.so/api/v1

Авторизация: заголовок Authorization: Bearer <API_TOKEN>. Ключи Upstream не возвращаются из API и остаются секретом владельца аккаунта. Использовать только официальный REST API или официальный MCP Upstream; не обращаться к недокументированным endpoint.

Документация API описывает управление streams, media, queues, schedules, destinations, start/stop и импорт медиа. Проверять фактические endpoint и JSON по текущей OpenAPI/API reference перед реализацией; не полагаться на придуманные маршруты.

## Текущий статус проекта

- GitHub Pages сайта МУЛЬТИК ТВ опубликован.
- Пульт вещания существует, но его серверные API placeholders пока не подключены.
- Upstream API key не получен и не настроен.
- Upstream stream/channel не создан.
- Destination для просмотра/публикации не подтверждён.
- Ни один эфир не запущен этим репозиторием.
- Автоматический поисковик и генератор мультфильмов пока не подключены.
- Бесплатный план Upstream не обеспечивает 24/7 вещание.

## Следующие шаги

1. Взрослый владелец аккаунта входит в Upstream и подтверждает подходящий план.
2. Владелец создаёт отдельный API key и настраивает безопасное хранилище секрета на сервере.
3. Подключаем read-only проверку аккаунта и списка потоков.
4. После подтверждения правильного потока настраиваем тестовую очередь из материалов с подтверждёнными правами.
5. Проверяем тестовый эфир, затем отдельно обсуждаем расписание и автоматизацию.

Не просить пользователя публиковать API key или stream key в чате. Если ключ случайно опубликован, владелец должен отозвать его и создать новый.
