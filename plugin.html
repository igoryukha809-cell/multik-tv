Бесплатный помощник эфира

Это веб-панель с инструкциями и ссылками для запуска домашнего видеосервера МУЛЬТИК ТВ. Программа сервера бесплатная и открытая. Сам сайт не может включить выключенный компьютер или запустить Docker на чужом устройстве.

Важно: сейчас публичный круглосуточный эфир не запущен. Сервер будет работать только после настройки на компьютере, где установлен Docker, и пока этот компьютер включён. Для установки, сетевых настроек и любого публичного доступа попроси взрослого помочь.

Запуск на компьютере Windows

1. Скачай файлы сервера

Открой ZIP-архив проекта и распакуй папку. Не запускай неизвестные файлы из сторонних источников.

Скачать файлы проектаDocker Desktop
2. Добавь разрешённые видео

Помести MP4, MKV, MOV или WebM в папку stream-server/media. Используй только свои видео или мультфильмы, для которых есть явное разрешение на публичный показ. Не загружай личные данные.

3. Запусти сервер

Открой папку stream-server и дважды нажми START-MULTIK-TV-WINDOWS.bat. Дождись завершения запуска Docker.

Что помощник может и чего не может

  • Помогает скачать исходники и найти сценарий запуска.
  • Даёт ссылку для проверки локального HLS-потока.
  • Сервер и плейлист автоматически перезапускаются Docker, пока компьютер включён.
  • Не создаёт бесплатный облачный сервер и не держит трансляцию после выключения компьютера.
  • Не открывает порты роутера и не публикует домашний IP. Для публичного эфира нужна отдельная безопасная настройка со взрослым.

Если видео нет, проверь папку media и логи командой docker compose logs -f из папки stream-server. Остановить сервер можно файлом STOP-MULTIK-TV-WINDOWS.bat.
