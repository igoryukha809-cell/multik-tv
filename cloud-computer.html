Облачный компьютер МУЛЬТИК ТВ

Подготовлена конфигурация GitHub Codespaces. Это браузерная среда разработки на удалённом Linux-компьютере: можно открывать файлы проекта, редактировать сайт и запускать команды без установки редактора на телефон.

Перед запуском

Попроси родителя или опекуна проверить настройки расходов GitHub. На личном бесплатном аккаунте обычно включено до 120 core-hours и 15 GB-month хранения в месяц; на машине с 2 ядрами это примерно 60 часов работы. После исчерпания бесплатной квоты запуск блокируется, если не настроена оплата; при подключённом способе оплаты возможны списания. Условия и квоты GitHub.

Не добавляйте способ оплаты ради запуска. Если на аккаунте уже есть платёжные настройки, взрослый должен убедиться, что расходы ограничены нулём.

Как открыть

  1. Откройте GitHub и войдите в аккаунт, которому доступен репозиторий.
  2. После проверки настроек расходов нажмите кнопку ниже.
  3. Выберите бесплатную конфигурацию с 2 ядрами, если она доступна, и создайте Codespace.
  4. Когда закончите, используйте меню Codespaces и выберите Stop. Не оставляйте среду работающей без надобности.

Что это умеет

  • Редактировать файлы сайта прямо в браузере.
  • Запускать команды и проверять код проекта.
  • Сохранять изменения обратно в GitHub.

Важно: Codespaces — временный облачный компьютер для разработки, а не круглосуточный видеосервер. Он не запускает эфир МУЛЬТИК ТВ 24/7 и автоматически останавливается при простое.

Конфигурация проекта подготовлена; сам Codespace создаётся владельцем аккаунта на стороне GitHub.
