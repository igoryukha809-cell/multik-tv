Открыть бесплатный пульт Открыть ТВ-плеер

Подготовка общего интернет-эфира

  1. Контент. Используй только собственные мультфильмы или материалы, для которых письменно разрешена публичная онлайн-трансляция. Сохраняй ссылку на лицензию и имя правообладателя.
  2. Видеосервер. Для общего потока нужен постоянно работающий компьютер или хостинг с поддержкой потокового видео. Бесплатный статический GitHub Pages этого не предоставляет.
  3. Поток. Сервер должен принимать видео и выдавать зрителям HLS/HTTPS-плейлист. Плеер сайта уже предназначен для воспроизведения готового HLS/MP4-адреса.
  4. Проверка. Сначала проверь эфир в закрытом тесте. Не публикуй домашний IP, не открывай порты роутера и не подключай неизвестные файлы/сервисы без помощи взрослого.

Важно: этот сайт и GitHub Actions не создают непрерывный видеопоток. Автопроверка плейлиста — это мониторинг, а не трансляция.

Проверка перед публикацией

  • Есть подтверждённые права на каждый фильм.
  • Источник видео стабилен и разрешает встраивание/публичный показ.
  • Есть постоянный видеосервер и понятный ответственный взрослый.
  • HLS-адрес открывается в плеере с другого устройства.
  • На странице канала честно указано, идёт ли эфир или это тест.

Пока эти условия не выполнены, канал не должен показывать статус «В эфире».
