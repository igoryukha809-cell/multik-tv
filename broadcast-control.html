🔌 Связь с PulseCast и Kinescope

Автоматическая синхронизация с PulseCast пока недоступна. В публичной документации PulseCast не обнаружен API для загрузки видео и редактирования плейлиста. Поэтому очередь, составленная здесь, не изменяет очередь PulseCast. Не останавливай работающий эфир ради этой настройки.

Сейчас можно подготовить очередь в GitHub и скачать её JSON-файлом. Чтобы изменить фактический эфир, владелец канала должен использовать панель PulseCast и выбрать там нужные видео. Kinescope принимает готовый RTMP-поток от PulseCast.
