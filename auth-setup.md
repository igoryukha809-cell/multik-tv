# Авторизация сайта — переход с Logto на VK ID

## Текущий статус

Ветка `rebuild-vkid-auth` готовит переход с Logto на VK ID. Новая авторизация ещё не подключена к API и не включена на рабочем сайте.

- `login.html` — новая страница VK ID; кнопка намеренно выключена до готовности сервера.
- `vkid-config.js` — публичная конфигурация; `VKID_APP_ID` пока равен `0`.
- `VKID-MIGRATION.md` — общий план перехода.
- `VKID-SERVER-IMPLEMENTATION.md` — проект серверной сессии, проверки пользователя и администраторских прав.
- `logto-config.js`, `admin-guard.js`, `admin.html`, `access-keys.html`, `storage-api/server.js` и `cloud-server/server.js` всё ещё содержат старую интеграцию Logto.

## Важное правило перехода

Не удаляйте старые настройки Logto и не отключайте старые серверные проверки, пока VK ID не пройдёт полный тест на отдельной ветке и не будет готов безопасный откат. Не смешивайте старую и новую проверку прав в одном запросе.

## Целевая схема VK ID

1. Пользователь начинает вход через официальный VK ID Web SDK.
2. SDK обрабатывает OAuth 2.1/PKCE и проверку `state`.
3. Сервер получает токен и сам запрашивает VK ID UserInfo.
4. Сервер использует только подтверждённый VK числовой ID; сведения, присланные браузером, не считаются доказательством личности.
5. Сервер создаёт непрозрачную сессию в постоянном хранилище.
6. Административные права выдаются только ID из серверного списка `VK_ADMIN_USER_IDS`.

Отдельный пароль сайта и ввод электронной почты не требуются.

## Что необходимо до включения

- Зарегистрировать приложение VK ID и указать его публичный числовой App ID.
- Зарегистрировать точный HTTPS callback URL.
- Настроить серверный список числовых VK ID администраторов.
- Выбрать схему доменов, при которой cookie-сессия не блокируется браузером (общий site origin или API-прокси).
- Подключить постоянное хранилище сессий.
- Перевести и проверить все защищённые API-маршруты, включая storage API и cloud server.
- Протестировать вход, выход, истечение и отзыв сессии, CSRF, права обычного пользователя и администратора.

## Старая конфигурация Logto

Файл `logto-config.js` и серверные переменные Logto оставлены только для текущей совместимости старой интеграции. Не используйте его как инструкцию для новой настройки. Удалить старую конфигурацию можно только после успешного развёртывания VK ID и проверки всех страниц и API.
