# Авторизация сайта и панели управления

Единый сервис управления сессиями — Logto. Пользовательский вход планируется через VK ID, подключённый как социальный провайдер Logto. GitHub-вход удалён из пользовательского сценария.

## Публичная конфигурация

Файл `logto-config.js` содержит публичные параметры SPA:

- Logto endpoint: `https://v74j2v.logto.app`
- SPA application ID: `gvfs0kxuu7rtdeqi3z0zm`
- API resource URI задаётся в конфигурации приложения и должен совпадать с серверной настройкой.

Client secret, токены и приватные ключи в этом файле хранить нельзя.

## Вход VK ID

Кнопка на `login.html` запускает Logto direct sign-in с провайдером `vk`. Коннектор должен быть настроен в Logto Console и иметь совместимый с текущим VK ID OAuth 2.1/PKCE поток. Стандартный OAuth 2.0 connector Logto документирован для Authorization Code, поэтому совместимость необходимо проверить до включения входа для пользователей.

Подробные шаги и ограничения: [VK-ID-SETUP.md](VK-ID-SETUP.md).

## Проверка администратора

Административные операции проверяются backend-сервисом по JWT:

- подпись проверяется через JWKS Logto;
- проверяются issuer, audience и срок действия;
- при наличии `ADMIN_LOGTO_SUBJECT` доступ разрешён только точному Logto user ID из claim `sub`;
- старый режим подтверждённого email оставлен как резервная совместимость, если `ADMIN_LOGTO_SUBJECT` не задан.

Для VK ID предпочтительно использовать `ADMIN_LOGTO_SUBJECT`, поскольку email не гарантирован и не должен быть единственным основанием для доступа.

## Административные страницы

- `login.html` — вход через VK ID через Logto.
- `access-keys.html` — управление техническими ключами после проверки backend.
- `admin.html` и страницы с `admin-guard.js` — закрыты серверной проверкой.

Нельзя считать пользователя администратором по данным из localStorage, JavaScript-переменным или одному факту успешной регистрации.

## Статус

Ветка `rebuild-vk-auth` содержит подготовленные изменения. Они ещё не опубликованы в основной ветке и не означают, что VK ID уже подключён. Сначала настройте VK ID и Logto, затем проведите тест входа и проверки прав.
