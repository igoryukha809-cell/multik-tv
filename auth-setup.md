# Настройка входа МУЛЬТИК ТВ по электронной почте

Страница: `login.html`. Реализован passwordless-вход по одноразовой ссылке (magic link) через Supabase Auth. Это **не** вход через ChatGPT/OpenAI.

## Что должен сделать владелец проекта (с участием взрослого администратора)

1. Создать проект Supabase и включить Authentication → Sign In / Providers → Email.
2. В Authentication → URL Configuration добавить точный адрес GitHub Pages сайта в Site URL и Redirect URLs, например:
   `https://igoryukha809-cell.github.io/multik-tv/login.html`
3. Скопировать Project URL и публичный anon/publishable key из настроек API проекта.
4. В `login.html` заменить `SUPABASE_URL` и `SUPABASE_ANON_KEY`. Публичный anon key предназначен для браузера; **никогда не использовать service_role key**.
5. Проверить отправку писем и вход по ссылке.

## Важная защита

- Одна лишь авторизация не даёт право управлять сервером. Все приватные данные должны быть защищены RLS-политиками на стороне Supabase.
- Не хранить пароли, service_role keys, API-токены или секреты в GitHub Pages и JavaScript.
- Не добавлять административные полномочия всем зарегистрированным пользователям. Для админов нужна отдельная серверная проверка ролей.
- До настройки проекта и ключей страница честно показывает инструкцию, а не имитирует успешный вход.
- GitHub Pages — статический хостинг; эта реализация не запускает облачный видеосервер.
