Собери собственную программу

Выбери видеофайлы со своего устройства, расставь их в нужном порядке и сохрани список. Видео остаются на устройстве: редактор ничего не загружает в интернет.

Важно: добавляй только собственные видео или материалы, для которых проверено разрешение на публичную трансляцию. Наличие файла у тебя не означает наличие прав на его эфир.

Как подключить список к серверу

  1. Скачай playlist.txt.
  2. Скопируй его в папку stream-server/media/ рядом с видеофайлами.
  3. Убедись, что имена файлов в списке совпадают с именами в папке. Один файл — одна строка.
  4. Перезапусти локальный отправитель командой docker compose restart playlist из папки stream-server.

Если список пуст или файл playlist.txt отсутствует, сервер использует обычный алфавитный порядок файлов. Поддерживаются MP4, MKV, MOV и WebM. При изменении списка во время показа он будет перечитан после завершения текущего прохода.
