Подключение видеопотока

Вставь HTTPS-адрес готового потока HLS (.m3u8) или прямого видеофайла MP4/WebM. Не вставляй пароли, токены доступа или приватные ссылки.

HLS (.m3u8) воспроизводится напрямую в браузерах с нативной поддержкой HLS. В Chrome и Firefox может потребоваться отдельный HLS-плеер. MP4/WebM поддерживаются при совместимом кодеке.

Что уже готово

  • Страница плеера размещается на GitHub Pages.
  • Можно подключить публичный HTTPS-поток.
  • Есть кнопки запуска и остановки воспроизведения.

GitHub Pages хранит страницу, но не кодирует видео и не раздаёт круглосуточный живой эфир. Для настоящего вещания нужен отдельный источник потока и сервер/CDN.
