# Онлайн-плейлист МУЛЬТИК ТВ

Этот каталог хранит расписание для статической страницы GitHub Pages.

## Как добавить передачу

В `playlist.json` добавь объект в `items`:

```json
{
  "title": "Название передачи",
  "url": "https://example.org/video.mp4",
  "startAt": "2026-12-01T10:00:00Z",
  "endAt": "2026-12-01T10:30:00Z",
  "rightsConfirmed": true
}
```

- Время указывается в UTC в формате ISO 8601.
- Поддерживаются публичные HTTPS-ссылки на MP4/WebM или HLS `.m3u8`.
- Хостинг видео должен разрешать воспроизведение с сайта (CORS для HLS).
- `rightsConfirmed` ставь `true` только если у канала есть разрешение на публичный показ именно этого видео.
- Не вставляй приватные ссылки, токены или пароли.

## Важное ограничение

GitHub Pages размещает страницу и JSON-расписание, но не принимает RTMP и не транскодирует/раздаёт видео как телеканал. GitHub Actions может проверять расписание по расписанию, но не является круглосуточным видеосервером. Видео по ссылкам хранятся у отдельного видеохостинга. Если видеофайлы недоступны публично или у них нет разрешения на публичный показ, эфир не заработает.
