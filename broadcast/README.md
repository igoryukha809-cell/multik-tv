# Плейлист МУЛЬТИК ТВ

Добавляй сюда только видео, на которые у канала есть явное право публичного показа.

## Формат записи

Каждый элемент массива `items` в `playlist.json` должен содержать:

- `title` — название видео;
- `url` — прямая общедоступная HTTPS-ссылка на файл;
- `rightsConfirmed` — `true` только после проверки, что правообладатель или лицензия действительно разрешают публичный показ;
- `license` — точное название лицензии или описание письменного разрешения;
- `attribution` — автор/правообладатель и текст указания авторства;
- `rightsEvidence` — ссылка на условия лицензии или описание, где хранится письменное разрешение.

Пример структуры (вымышленный пример, не реальный видеоматериал):

```json
{
  "title": "Название собственного ролика",
  "url": "https://example.org/my-video.mp4",
  "rightsConfirmed": true,
  "license": "Собственное произведение; права принадлежат каналу",
  "attribution": "Автор: команда МУЛЬТИК ТВ",
  "rightsEvidence": "Письменное подтверждение хранится у правообладателя"
}
```

## Что проверяет робот

Автопроверка проверяет структуру, HTTPS-ссылку и заполнение полей о правах. Она **не проверяет юридическую действительность лицензии**, не скачивает видео и не запускает эфир. Статус `playlist_ready_server_required` означает только, что запись прошла проверку заполнения; для трансляции всё равно нужен работающий видеосервер.

Публичная доступность ролика, бесплатный просмотр или наличие видео на видеохостинге сами по себе не дают права на ретрансляцию.
