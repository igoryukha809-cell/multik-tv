# Локальные программы МУЛЬТИК ТВ

Помещайте в эту папку видео, созданные каналом или предоставленные с разрешением на публичный показ. Сервер автоматически подхватит файлы `.mp4`, `.m4v`, `.mov` и `.webm` при сборке контейнера; отдельный флаг подтверждения для каждого локального файла не нужен.

Чужие передачи без разрешения сюда добавлять нельзя. Внешние загрузки по URL остаются отдельным режимом и требуют настройки прав.
