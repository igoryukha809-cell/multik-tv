Я подготовил для проекта собственную конфигурацию сервера на бесплатном программном обеспечении SRS, FFmpeg и Docker Compose. Сервер принимает видео, формирует HLS-поток и последовательно воспроизводит файлы из локальной папки.

Честно: серверный код создан в репозитории, но он ещё не запущен на твоём устройстве или в интернете. Эта страница не может включить компьютер или создать облачный сервер вместо владельца аккаунта.

Запуск на своём компьютере

  1. Попроси взрослого помочь установить Docker Desktop с официального сайта Docker.
  2. Открой репозиторий и скачай его через GitHub: исходный код МУЛЬТИК ТВ.
  3. В папку stream-server/media/ положи собственные видео или материалы с подтверждённым разрешением на публичный показ.
  4. В Windows запусти stream-server/start-local.bat. На macOS/Linux выполни cd stream-server && bash start-local.sh.
  5. Проверь контейнеры командой docker compose ps в папке stream-server.

Адреса локального сервера

  • HLS-видеопоток: http://localhost:8080/live/multiktv.m3u8
  • RTMP-вход для внутреннего отправителя: rtmp://localhost/live/multiktv

Эти адреса работают на том компьютере, где запущен Docker. Сейчас порты намеренно привязаны к localhost: это не открывает домашнюю сеть всему интернету.

Что важно знать

  • Если папка с видео пуста, сервер передаёт только явно обозначенную техническую заставку.
  • Сервер не скачивает мультфильмы из интернета и не обходит ограничения правообладателей.
  • Для общего доступа из интернета нужен отдельный безопасный HTTPS-домен или прокси, который настраивает взрослый.
  • Круглосуточная работа требует постоянно включённого устройства, электричества и стабильного интернета. Бесплатное ПО не означает бесплатный хостинг.

Не публикуй домашний IP, не открывай порты роутера и не добавляй платёжные данные самостоятельно.
