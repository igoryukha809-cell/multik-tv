Собственный видеосервер на открытом ПО. Он запускается на компьютере или на выбранном вами сервере под вашим контролем. Панель и сайт канала остаются на GitHub Pages, а видео передаёт отдельный сервер SRS.

📡 Видеосервер SRS

Принимает RTMP-входящий поток и публикует HLS для просмотра в плеере.

🎞️ Автоплейлист

FFmpeg последовательно воспроизводит локальные видеофайлы из папки media и повторяет список.

🔄 Перезапуск

Docker Compose перезапускает контейнеры после сбоев, пока компьютер и Docker работают.

🛡️ Безопасность

По умолчанию запускайте только в домашней сети. Не открывайте порты в интернет и не публикуйте домашний IP самостоятельно.

Первый запуск

  1. На компьютере установите Docker Desktop с официального сайта: docker.com.
  2. Скачайте репозиторий МУЛЬТИК ТВ и откройте папку stream-server.
  3. Поместите в media только собственные видео или материалы с явным разрешением на публичный показ.
  4. Запустите Docker Compose командой docker compose up -d --build.
  5. Откройте HLS-поток на этом компьютере: http://localhost:8080/live/multiktv.m3u8
