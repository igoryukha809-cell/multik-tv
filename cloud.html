Как это работает бесплатно

  • Страница размещена на GitHub Pages бесплатно.
  • Видеофайлы хранятся в локальной базе браузера на устройстве.
  • Плейлист воспроизводится по очереди, с повтором при включённой настройке.
  • Для автоматического старта по времени страница должна быть открыта.

Важно: это работающий локальный эфир в открытом браузере, а не единый интернет-канал 24/7. GitHub Pages не передаёт видео зрителям и не хранит твои видеофайлы. Чтобы все зрители смотрели один общий поток круглосуточно, нужен постоянно работающий видеосервер и достаточный трафик. Бесплатная веб-страница не может заменить сервер. Не загружай и не транслируй чужие мультфильмы без разрешения правообладателя.
